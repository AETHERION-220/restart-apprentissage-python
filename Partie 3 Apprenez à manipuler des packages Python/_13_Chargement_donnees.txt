Le chargement de donnees avec Python

Python permet de lire et d'ecrire des donnees dans des fichiers.
C'est une competence tres importante pour manipuler des donnees.

Deux types de fichiers sont souvent utilises :

- les fichiers .txt
- les fichiers .csv

On peut lire et ecrire ces fichiers avec les fonctions de Python ou avec le package csv.

Lire et ecrire avec open()

La fonction open() permet d'ouvrir un fichier.
Elle prend deux arguments principaux :

- le nom du fichier
- le mode d'ouverture

Modes principaux :

- "r" : lecture
- "w" : ecriture (ecrase le fichier)
- "a" : ajout (ajoute a la fin du fichier)
- "r+" : lecture et ecriture

Exemple pour creer un fichier texte :

fichier = open("hello.txt", "w")
fichier.write("Hello, world!")
fichier.close()

Cela cree un fichier hello.txt et y ecrit le texte Hello, world!

On peut aussi utiliser with open() pour fermer automatiquement le fichier.

with open("file.txt", "r") as fichier:
    for ligne in fichier:
        print(ligne)

Dans ce cas, le fichier est automatiquement ferme a la fin du bloc.

Le package csv

Le module csv permet de lire et d'ecrire facilement des fichiers CSV.

Un fichier CSV est un fichier texte organise en colonnes separees par des virgules.

Exemple de fichier CSV :

nom,metier,couleur_preferee
Jacob Smith,Ingenieur en informatique,Violet
Nora Scheffer,Strategiste numerique,Bleu
Emily Adams,Responsable Marketing,Orange

Pour lire un fichier CSV, on utilise csv.reader().

Exemple :

import csv

with open("couleurs_preferees.csv", "r") as fichier_csv:
    reader = csv.reader(fichier_csv, delimiter=',')
    for ligne in reader:
        print(ligne)

Le resultat sera une liste pour chaque ligne.

Exemple de sortie :

['nom', 'metier', 'couleur_preferee']
['Jacob Smith', 'Ingenieur en informatique', 'Violet']
['Nora Scheffer', 'Strategiste numerique', 'Bleu']
['Emily Adams', 'Responsable Marketing', 'Orange']

Utiliser DictReader()

La methode DictReader() est tres pratique.
Elle lit la premiere ligne comme entete et cree un dictionnaire pour chaque ligne.

Exemple :

import csv

with open("couleurs_preferees.csv", "r") as fichier_csv:
    reader = csv.DictReader(fichier_csv, delimiter=',')
    for ligne in reader:
        print(ligne['nom'] + " travaille en tant que " + ligne['metier'] + " et sa couleur preferee est " + ligne['couleur_preferee'])

Le resultat sera :

Jacob Smith travaille en tant que Ingenieur en informatique et sa couleur preferee est Violet
Nora Scheffer travaille en tant que Strategiste numerique et sa couleur preferee est Bleu
Emily Adams travaille en tant que Responsable Marketing et sa couleur preferee est Orange

Ecrire dans un fichier CSV

Pour ecrire des donnees dans un fichier CSV, on utilise csv.writer().

Exemple :

import csv

en_tete = ["titre", "description"]

with open("data.csv", "w", newline="") as fichier_csv:
    writer = csv.writer(fichier_csv, delimiter=',')
    writer.writerow(en_tete)

    donnees = [
        ["Titre 1", "Description 1"],
        ["Titre 2", "Description 2"]
    ]

    for ligne in donnees:
        writer.writerow(ligne)

Cela cree un fichier data.csv avec les donnees voulues.

Le mot cle newline="" est utile pour eviter les problemes de lignes sur Windows.

Exemple concret d'utilisation

Supposons que vous avez une liste de titres et de descriptions extraites du web.
Vous pouvez ensuite les ecrire dans un CSV :

import csv

titres = ["Article 1", "Article 2"]
descriptions = ["Description 1", "Description 2"]

with open("data.csv", "w", newline="") as fichier_csv:
    writer = csv.writer(fichier_csv, delimiter=',')
    writer.writerow(["titre", "description"])

    for titre, description in zip(titres, descriptions):
        writer.writerow([titre, description])

La fonction zip() permet de parcourir plusieurs listes en meme temps.

Bonnes pratiques

- utilisez with open() pour fermer automatiquement les fichiers
- utilisez csv.reader() ou csv.DictReader() pour lire des fichiers CSV
- utilisez csv.writer() pour ecrire des fichiers CSV
- choisissez le bon mode : r, w, a
- nommez vos fichiers de maniere claire

En resume

- open() sert a lire ou ecrire des fichiers
- csv permet de manipuler des fichiers CSV plus facilement
- DictReader() est tres utile quand le fichier contient des entetes
- writer() permet de sauvegarder des donnees dans un fichier CSV
- les fichiers sont utiles pour stocker des donnees et les reutiliser plus tard

Les fichiers et les CSV sont essentiels pour prendre et sauvegarder des donnees dans des projets Python.
